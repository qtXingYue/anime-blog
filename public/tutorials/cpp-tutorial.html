CHAPTER 01 · 入门准备

认识 C++：为什么值得学？

📌 本章目标：搞清楚 C++ 是什么、能做什么，并理解「源代码 → 编译 → 运行」的基本流程。

C++ 是什么？

C++ 是一门 1979 年诞生于贝尔实验室的编程语言，作者是 Bjarne Stroustrup（本贾尼·斯特劳斯特卢普）。它最初叫「C with Classes」（带类的 C），1983 年正式改名为 C++ —— ++ 正是 C 语言里的「自增」运算符，寓意「C 的增强版」。

一句话概括它的性格：跑得快、管得细、本事大。它既像 C 语言一样贴近硬件、性能极高，又提供了「面向对象」等现代化的武器，四十多年长盛不衰，至今仍是全球最流行的编程语言之一。

C++ 都用在哪里？

你每天用到的软件，很多核心部分都是 C++ 写的：

🎮游戏引擎虚幻引擎、Unity 的底层都是 C++，王者荣耀、原神都离不开它
🖥️操作系统Windows、macOS 的大量核心组件由 C++ 编写
🗄️数据库MySQL、MongoDB、Redis 的核心是 C/C++
🤖AI 框架PyTorch、TensorFlow 的底层计算引擎是 C++
💰金融系统高频交易系统用它追求微秒级的速度
🚗嵌入式汽车、家电、机器人等智能设备的程序

程序是怎么跑起来的？

电脑的 CPU 只认识 0 和 1，并不认识 C++。所以你写好的代码（叫源代码）需要一位「翻译官」——编译器——把它翻译成电脑能直接执行的文件，然后运行才能看到结果：

图 1-1 从源代码到运行结果：编译器是人和机器之间的「翻译官」
📝 小词典

源代码：你用文字写的程序文件（如 hello.cpp）；编译：把源代码翻译成机器能执行的文件；可执行文件：翻译后的成品（Windows 上是 .exe）；控制台：那个黑乎乎的窗口，程序在里面和你「对话」。

💡 新手建议

C++ 的概念确实比 Python 多一些，但这恰恰能让你真正理解「程序是怎么在电脑里跑的」，学完再学其他语言会非常轻松。本教程基于 C++11 及以上标准，跟着一章一章敲代码，零基础完全可以学会。

搭建开发环境：准备好你的「厨房」

📌 本章目标：装好一个能写 C++ 的工具，并知道「编译」和「运行」命令是怎么回事。

三条路，选一条就行

写 C++ 需要两样东西：编译器（翻译官）和编辑器（写代码的地方）。把它们打包在一起的软件叫 IDE（集成开发环境）。下面三条路任选其一即可：

方式适合谁特点
Dev-C++完全新手（推荐）一个安装包全搞定，国内学校机房常用，界面简单
VS Code + MinGW想用现代编辑器长期学习界面漂亮、插件多，但安装配置步骤多一点
在线编译器装不了软件 / 先试试水打开网页就能写，零安装

方式一：Dev-C++（新手推荐）

  1. 下载安装：搜索「小熊猫 Dev-C++」（Red Panda Dev-C++，是维护更活跃的升级版）或经典 Dev-C++，一路「下一步」装完。
  2. 新建文件：打开软件，按 Ctrl + N 新建一个源代码。
  3. 保存：按 Ctrl + S 保存为 hello.cpp。建议先在桌面建一个 cpp-learn 文件夹统一存放，文件名不要用中文。
  4. 运行：写下第 3 章的第一个程序，按 F11（编译并运行）。弹出黑色窗口显示结果，就说明环境搭好了！

方式二：VS Code + MinGW

  1. 安装编译器：从 winlibs.com 下载 MinGW-w64 解压版（或用 MSYS2 安装），记住解压路径，例如 C:\mingw64。
  2. 配置环境变量：把 C:\mingw64\bin 加入系统 PATH（设置 → 搜索「环境变量」 → 编辑 Path → 新建）。
  3. 验证：Win + R 输入 cmd 打开一个新的命令行窗口，输入 g++ --version，能看到版本号就成功了。
  4. 安装 VS Code 与官方「C/C++」扩展，新建 .cpp 文件后点右上角 ▶ 按钮运行。
💡 macOS 用户看这里

苹果电脑自带 clang 编译器：打开「终端」，输入 xcode-select --install 安装命令行工具，之后 g++ hello.cpp -o hello 的命令同样可用（此时 g++ 实际指向 clang）。

方式三：在线编译器（零安装）

打开「菜鸟教程在线工具」或 OnlineGDB 等网站，语言选择 C++，就能直接写代码点「运行」。适合快速试代码，但正式学习建议还是装一个本地环境。

变量与数据类型：给数据安个家

📌 本章目标：理解变量是「内存里的储物格」，掌握 5 种常用类型，学会给变量起好名字，避开整数除法的坑。

变量是什么？

程序要处理数据，数据需要放在内存里。变量就是内存里的一格储物空间：它有名字（方便你找到它）、有类型（决定格子多大、能放什么）、有值（里面放的东西，可以随时更换）。

图 4-1 每个变量都是内存里的一格：有类型、有名字、有值，还有个地址

五种最常用的类型

📄 types.cpp
#include <iostream>
#include <string>      // 使用 string 要额外包含它
using namespace std;

int main() {
    int    age    = 18;      // 整数
    double height = 1.75;    // 小数（浮点数）
    char   grade  = 'A';     // 单个字符，用单引号

    string name   = "小明";   // 字符串（一串字符），用双引号

    cout << "身高：" << height << endl;
    cout << "等级：" << grade  << endl;
    cout << "是男生吗：" << isBoy << endl;

C++ 里 true 本质上就是 1、false 是 0。想让它显示 true/false，在输出前加一句 cout << boolalpha; 即可。

cout << "int 占 " << sizeof(int) << " 字节" << endl;      // 4
cout << "double 占 " << sizeof(double) << " 字节" << endl;  // 8

变量的命名规则

  • 只能由字母、数字、下划线组成，且不能以数字开头（2name ❌，name2 ✔）。
  • 区分大小写：Age 和 age 是两个不同的变量。
  • 不能用关键字（如 int、return）作名字。
  • 起名要有意义：score 好，a、x1 差。多个单词推荐「驼峰式」：maxScore、userName。

常量：不许改动的值

有些值从头到尾不该变，比如圆周率。加上 const，谁改它就报错：

const.cpp
const double PI = 3.14159;   // 常量：初始化后不能再改
PI = 3.14;                   // ❌ 编译报错！不许修改常量

一定要避开的坑：整数除法

两个整数相除，结果还是整数——小数部分直接被砍掉（不是四舍五入）：

divide.cpp
int a = 5, b = 2;
cout << a / b << endl;     // 2   ← 整数除法，0.5 被丢掉了！
cout << a % b << endl;     // 1   ← % 取余数（只对整数有效）
cout << 5.0 / 2 << endl;   // 2.5 ← 只要有一个是小数，就按小数除

double x = 3.9;
int y = (int)x;            // 强制类型转换：得到 3（直接砍掉小数）
cout << y << endl;
💡 想要 2.5 怎么办？

让参与除法的数至少有一个是小数：5.0 / 2，或者先转换 (double)a / b。这个坑以后写「求平均分」时几乎人人会踩一次。

输入与输出：程序和用户对话

📌 本章目标：熟练使用 cout 输出、cin 读入用户输入，学会保留小数位数的格式化输出。

数据流动的方向

cin（读作 see-in）把用户敲的字读进变量；cout（see-out）把内容输出到屏幕。箭头方向就是数据流动的方向，非常好记：

图 5-1 cin 和 cout：箭头永远指向数据流去的方向

cin：把输入装进变量

📄 input.cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "请输入你的年龄：";
    cin >> age;                          // 读入一个整数，存进 age
    cout << "明年你就 " << age + 1 << " 岁啦" << endl;

    double x, y;
    cout << "请输入两个数（空格分隔）：";
    cin >> x >> y;                       // 一次读两个，用空格或回车分隔
    cout << x << " + " << y << " = " << x + y << endl;
    return 0;
}
▶ 运行结果
请输入你的年龄：17
明年你就 18 岁啦
请输入两个数（空格分隔）：3.5 2
3.5 + 2 = 5.5

读一句话：getline

cin >> 遇到空格就停止，读不了「New York」这样带空格的句子。想读一整行，用 getline：

getline.cpp
string city;
cout << "你想去哪个城市？";
getline(cin, city);              // 读入一整行，包括空格
cout << city << " 是个好地方！" << endl;
⚠️ cin 和 getline 混用的小坑

先用 cin >> 再用 getline 时，cin 会把残留的「回车」留给 getline，导致它读到空内容。新手阶段可以先避免混用；解决办法是在 getline 前加一句 cin.ignore(); 把残留的回车吃掉。

格式化输出：控制小数位数

算出 12.56636 这种一长串小数很难看。用 <iomanip> 里的 fixed 和 setprecision 控制保留几位：

format.cpp
#include <iostream>
#include <iomanip>    // setprecision 住在这里
using namespace std;

int main() {
    double r = 2.0;
    double area = 3.14159 * r * r;
    cout << area << endl;                        // 12.5664（默认保留到有效位）
    cout << fixed << setprecision(2) << area << endl;  // 12.57（固定 2 位小数）
    return 0;
}

assign.cpp

关系运算符：比较大小

比较的结果是 bool 值（真 true / 假 false），它是第 7 章 if 判断的原料：

compare.cpp
int a = 5, b = 3;
cout << (a > b) << endl;    // 1（真）
cout << (a == b) << endl;   // 0（假）  == 是「等于吗？」
cout << (a != b) << endl;   // 1（真）  != 是「不等于吗？」

逻辑运算符：把多个条件串起来

运算符含义真记忆
&&与（并且）两边都真才真「既要…又要…」
||或（或者）一边真就真「有一样就行」
!非（取反）真假互换「唱反调」
logic.cpp
int age = 20;
bool hasTicket = true;

// 年满 18 并且有票，才能进场
cout << (age >= 18 && hasTicket) << endl;   // 1

// 周六或周日放假（假设 day = 6 表示周六）
int day = 6;
cout << (day == 6 || day == 7) << endl;     // 1

// 逻辑与还有「短路」特性：左边能定结论，右边就不算了
int x = 0;
bool r = (x != 0) && (10 / x > 1);   // 左边为假 → 右边 10/x 根本不执行，避免了除零！

优先级：谁先算？

完整优先级表有几十条，新手只需记住这条简化口诀：

📌 优先级口诀（从高到低）

括号 () → 自增自减 → 乘除取余 * / % → 加减 + - → 比较 > < == != → 逻辑 && → 逻辑 || → 赋值 =

拿不准就加括号——加括号永远不会错，还能让代码更好读。

📌 本章目标：会定义、调用函数，理解参数传递和返回值，了解默认参数与函数重载。

为什么需要函数？

同一段「求和」代码如果要在 10 个地方用，复制粘贴 10 遍太蠢了。函数就像一台洗衣机：把脏衣服（参数）放进去，按开始（调用），拿回干净衣服（返回值）。写一次，到处用。

图 9-1 函数调用：main 把参数传给函数，函数把结果还给 main

定义与调用

📄 add.cpp
#include <iostream>
using namespace std;

// 返回类型  函数名(参数列表)
int add(int a, int b) {
    return a + b;        // 把计算结果还给调用者
}

int main() {
    int s = add(3, 5);           // 调用函数，s 得到 8
    cout << "3 + 5 = " << s << endl;
    cout << add(10, 20) << endl; // 返回值也可以直接输出
    return 0;
}
  • 形参（a、b）是函数的「收件地址」，实参（3、5）是真正寄出的值。
  • 不需要返回值时，返回类型写 void，函数里可以不写 return（或只写 return;）。
  • 如果函数定义在 main 之后，需要在 main 前先写一行声明：int add(int a, int b);——新手最简单的做法是把所有函数写在 main 上面。

值传递 vs 引用传递（重要！）

默认情况下，函数拿到的是实参的复印件（值传递），改复印件不影响原件。参数前加 & 就变成拿原件（引用传递）：

swap.cpp
#include <iostream>
using namespace std;

void swapWrong(int a, int b) {    // 值传递：只交换了复印件
    int t = a; a = b; b = t;
}

void swapRight(int &a, int &b) { // 引用传递：直接操作原件
    int t = a; a = b; b = t;
}

int main() {
    int x = 1, y = 2;
    swapWrong(x, y);
    cout << x << " " << y << endl;   // 1 2 （没换成功）
    swapRight(x, y);
    cout << x << " " << y << endl;   // 2 1 （换成功了！）
    return 0;
}

指针与引用：直捣内存深处

📌 本章目标：理解「地址」概念，会使用指针（取地址 &、解引用 *）和引用，分清两者的适用场景。

先建立直觉：内存像一家酒店

变量住进内存这家酒店：值是房间里的客人，地址是房间号。&a 查房间号，指针 p 是一张「写着房间号的纸条」，拿着纸条（*p）就能找到那个房间、进出里面的人。

图 12-1 p 存着 a 的地址，*p 就是「a 的值」的另一种访问方式

指针三板斧：&、*、nullptr

📄 pointer.cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int* p = &a;         // p 存了 a 的地址（& 读作「取地址」）

    cout << &a << endl;  // 0x6ffe14 之类的地址（每次运行可能不同）
    cout << p  << endl;  // 同上：p 里存的就是这个地址
    cout << *p << endl;  // 10（* 读作「取内容」，顺着地址找到 a）

    *p = 20;             // 通过指针修改 a
    cout << a << endl;   // 20

    int* q = nullptr;    // 空指针：暂时不指向任何地方
    if (q != nullptr) {  // 先判空再用，安全第一！
        cout << *q << endl;
    }
    return 0;
}
⚠️ 野指针：程序崩溃的头号元凶

刚声明的指针里是随机垃圾值，直接 *p 去用它，程序轻则输出乱码、重则崩溃。规矩是：指针要么指向有效变量，要么置为 nullptr，解引用前先判空。

引用：变量的「别名」

引用比指针简单：int& r = a; 之后 r 就是 a 的另一个名字，操作 r 就是操作 a：

cout << a << endl;   // 30
cout << &r << " " << &a << endl;   // 地址完全相同

封装：把「不许碰」的数据保护起来

private 的成员外面摸不到，只能通过 public 的函数访问——这样数据就只能被「受控地」修改，比如成绩不允许设成 120 分：

📄 student-class.cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:                       // 私有区：外面不能直接碰
    string name;
    double score;

public:                        // 公开区：外界通过这些函数使用类
    // 构造函数：与类同名、无返回类型，创建对象时自动调用
    Student(string n, double s) {
        name  = n;
        score = s;
    }

    void show() {              // 成员函数：行为
        cout << name << " 的成绩是 " << score << endl;
    }

    void setScore(double s) {  // 受控的修改入口，可以加校验
        if (s >= 0 && s <= 100)
            score = s;
        else
            cout << "成绩必须在 0~100 之间！" << endl;
    }
};

int main() {
    Student stu("小明", 92.5);   // 创建对象（自动调用构造函数）
    stu.show();                  // 小明 的成绩是 92.5

    stu.setScore(120);           // 成绩必须在 0~100 之间！
    stu.setScore(88);
    stu.show();                  // 小明 的成绩是 88
    return 0;
}

Student(string n, double s) : name(n), score(s) {}

冒号后面这叫「初始化列表」，效果和函数体里赋值一样，实际工程更常用。

继承：站在父类的肩膀上

猫和狗都有「吃」「睡」等共同点，把这些放进父类 Animal，子类只补充自己的特色——代码不用重复写：

图 14-2 继承：子类自动拥有父类的能力，并可以重写自己的版本
inherit.cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() { cout << "吃东西" << endl; }
    virtual void speak() { cout << "..." << endl; }
    // virtual：允许子类重写这个函数
};

class Dog : public Animal {      // 读作：Dog 是一种 Animal
public:
    void speak() override {      // 重写父类的 speak
        cout << "汪汪！" << endl;
    }
};

class Cat : public Animal {
public:
    void speak() override {
        cout << "喵~" << endl;
    }
};

int main() {
    Dog d; Cat c;
    d.eat();   d.speak();    // 汪汪！（eat 是继承来的，speak 是重写的）
    c.eat();   c.speak();    // 喵~

    Animal* a = &d;          // 用父类指针指向子类对象
    a->speak();              // 汪汪！ ← 多态：同一句话，不同对象有不同反应
    a = &c;
    a->speak();              // 喵~
    return 0;
}

多态（polymorphism）正是上面的名场面：同样是 a->speak()，指向狗就叫「汪汪」，指向猫就叫「喵」。调用哪个版本由对象的实际类型在运行时决定。父类指针访问成员用 ->（而不是 .）。

🎭多态同一个接口，不同对象有不同实现，程序更灵活

📄 vector.cpp
#include <iostream>
#include <vector>
#include <algorithm>    // sort 住在这里
using namespace std;

int main() {
    vector<int> v;        // 不用预先指定长度！
    v.push_back(3);       // 尾部添加元素
    v.push_back(1);
    v.push_back(2);

    cout << v.size() << endl;    // 3（当前元素个数）
    cout << v[0] << endl;        // 3（下标访问和数组一样）

    sort(v.begin(), v.end());    // 排序：默认从小到大
    for (int x : v) cout << x << " ";   // 1 2 3
    cout << endl;

    sort(v.begin(), v.end(), greater<int>());   // 传 greater 就是从大到小
    for (int x : v) cout << x << " ";   // 3 2 1
    return 0;
}

#include <iostream>

int main() {

                 << "，你一共猜了 " << count << " 次" << endl;
        }
    } while (guess != answer);         // 没猜中就继续

    return 0;
}

    if (students.empty()) return;
    sort(students.begin(), students.end(), [](const Student& a, const Student& b) {
        return a.score > b.score;           // 成绩从高到低
    });
    cout << "已按成绩从高到低排序：" << endl;
    showAll();
}

// ---------- 主程序 ----------
int main() {
    cout << "====== 学生成绩管理系统 ======" << endl;

    while (true) {
        cout << "\n1.添加学生  2.显示全部  3.查找最高分  4.按成绩排序  0.退出"
             << endl;
        cout << "请选择：";
        int choice;
        cin >> choice;
        if (choice == 0) break;

        switch (choice) {
            case 1: addStudent();  break;
            case 2: showAll();     break;
            case 3: findMax();     break;
            case 4: sortByScore(); break;
            default: cout << "无效选项，请重新输入" << endl;
        }
    }
    cout << "已退出，再见！" << endl;
    return 0;
}
💡 两处新面孔

① auto：让编译器根据右边自动推断类型，auto& s : students 就是「挨个引用每个学生」，比写全名省事；② lambda [](...){...} 是匿名小函数，这里只用来告诉 sort 排序规则，第 15 章讲过。

调试五板斧（顺序使用，百试不爽）

  1. 只看第一条报错：编译器一次只可靠地报告一个问题，后面的报错常常是它引起的连锁反应。修复第一条，再重新编译。
  2. 读懂 / 搜索报错：报错行号会告诉你位置；看不懂就把报错原文复制去搜索引擎，99% 的新手报错都已有现成答案。
  3. print 大法：在可疑位置插入 cout << "到这里了, x=" << x << endl;，观察变量到底变成多少——最朴素也最强大。
  4. 注释二分法：注释掉一半代码再跑，问题还在吗？在 → 问题在被注释的那半；不在 → 在剩下的半。几次就能锁定出错的行。
  5. 小黄鸭调试法 🦆：把代码逐行大声讲给桌上的小黄鸭（或任何人）听——解释的过程常常让你自己发现 bug。

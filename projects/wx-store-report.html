01项目概述

基于 Java Servlet MVC 架构的后端 + 微信小程序 前端的完整电商应用。后端提供 7 个 Servlet 控制器，覆盖商品 CRUD、图片上传、批量删除等核心功能，通过 Jackson JSON 序列化与小程序通信。小程序端 6 个页面实现首页浏览、列表搜索、详情查看、编辑管理等完整购物流程。

02技术架构

层次技术职责
数据库MySQL 8.0db_store 库，tb_product 表（_id/name/price/source/image）
实体层Java Bean (Product)商品属性映射
数据访问DAO 模式SQL 查询、CRUD 操作、批量删除
业务逻辑Service 层数据验证、请求封装、业务编排
控制层Servlet（7 个控制器）HTTP 请求路由、JSON 响应（Jackson）
前端微信小程序WXML / WXSS / JS，6 个页面

03Servlet API 接口

Servlet功能HTTP

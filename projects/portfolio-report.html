01项目概述

这是一个从域名选型、UI/UX 交互设计、Astro 5 前端架构、Python 异步后端到云端生产运维全部独立完成的全栈技术作品集。核心设计理念是极致性能（0 白屏）、无缝交互（Fluid SPA Transition）与专业严谨的工程落地。

全站摒弃笨重的第三方 UI 模板，核心动效引擎、双主题感知色彩、每一个接口逻辑与 Nginx 反向代理配置皆为手工打磨；边缘侧接入 Cloudflare，源站 IP 隐身、静态资源全球边缘缓存。

04核心功能与交互创新

1. Astro 5 ClientRouter 流体路由与 Turbo Loader

全站采用 Astro 5 硬件加速的 <ClientRouter /> 架构接管路由，消除传统静态网站多页面切换时的白屏与生硬闪烁。页面跳转时辅以 2.5px 顶部紫金流光加载进度条（Turbo Top Loader） 与 物理弹性平滑滑动（Slide & Fade），让多页面静态站点拥有丝滑单页 Web App 的极速触感。

2. 3 列非对称 Bento Grid（便当盒网格布局）

专题项目区域采用 3 列非对称 Bento Grid 设计：核心亮点项目（如 ComfyUI AI 艺术画廊、CartoonCGAN 动漫风格迁移）跨越 2 列大卡展示，次要工具与实用项目采用 1 列紧凑卡片。打破常规列表的单调感，构建主次分明的视觉节奏。

3. Before / After 交互式图像对比引擎

在 AI 图像处理与风格迁移项目详情中，自研了轻量级、零外部依赖的交互对比滑块组件（ImageCompare.astro）。利用 CSS 变量 --pos 与硬件加速 clip-path: polygon()，支持鼠标拖拽、手势滑动、发光中线拉手与磨砂玻璃角标，直观展示真机实测前后的细节对比。

4. 移动端极致交互优化

分类吸顶胶囊导航（Sticky Tab Bar）
移动端专属 4 模块分类胶囊，随滚动双向高亮同步，点击平滑直达对应项目分区
沉浸式图片大图灯箱（Lightbox）
全站图表、架构图、界面截图支持一键全屏放大预览，支持 ESC 键与手势关闭
代码块一键复制与智能语言标识
自动解析 Prism/Shiki 代码块类型，右上角悬浮一键复制按钮与反馈动效

5. 黑金开屏加载动画（Splash）

首次进入站点时呈现的定制开屏：金色圆环以 stroke-dashoffset 描边展开，「月」字印章式压印浮现，随后进度线填充、幕布以 clip-path 上提揭幕。全流程纯 CSS 合成层实现，无图片、无额外请求。

工程上做了三处克制：会话内只出现一次（sessionStorage 标记，内部路由跳转绝不重复）；资源就绪即走但设有最短展示时长（移动端 2.0s / 桌面 1.65s），避免移动端缓存命中时一闪而过；三重兜底（JS 4.2s 硬超时 + CSS 4.8s 强制淡出 + 内联脚本 5.2s 摘遮罩）确保任何环节异常都不会把人锁在遮罩里。同时尊重 prefers-reduced-motion，点击或 Esc 可跳过。

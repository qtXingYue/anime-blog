01项目简介

这个项目是一个面向巴西企业 CNPJ 税号的批量查询脚本。脚本从 CNPJ-100.xlsx 的指定工作表读取企业记录，提取公司名、CNPJ、经营活动和预计资本等原始字段；随后通过 requests.Session 调用 BrasilAPI 的 CNPJ 接口，补充企业注册状态、法律性质、CNAE 主营业务、开业日期、注册资本、企业规模、地址、联系方式、Simples/MEI 选项等结构化信息。

项目定位是接口批处理与数据清洗脚本，重点在于把 Excel 中不规则排布的线索数据清洗成可复用的企业信息数据集，并保留完整 JSON 原文用于复核。

对应实现包含 cnpj_batch_query_v2.py、CNPJ-100.xlsx 和 cnpj_results/ 导出目录。

02处理流程

Excel 工作表 ↓ 按每 5 行提取一条企业记录 字段：序号 / 公司名 / CNPJ / 经营活动 / 预计资本 ↓ CNPJ 清洗 - 去掉 . - / 等分隔符 - 统一为数字串 ↓ BrasilAPI 查询 - GET /api/cnpj/v1/{cnpj} - requests.Session 复用连接 - 20 秒超时 ↓ 字段映射与汇总 - 合并 Excel 原始字段 - 补充 API 返回字段 ↓ 导出结果 - 单企业 JSON - 汇总 CSV - 失败列表 CSV - 完整批次 JSON

03核心功能

Excel 批量读取
使用 pandas.read_excel 读取指定 sheet，并按每 5 行一组解析企业记录。
CNPJ 标准化
通过正则清理 .、-、/，兼容带分隔符的税号格式。
BrasilAPI 查询
调用 https://brasilapi.com.br/api/cnpj/v1/{cnpj}，获取企业注册与经营信息。
节流控制
每次查询后短暂停顿，每 10 条额外等待，降低连续请求对公共接口的压力。
结果留痕
每个成功 CNPJ 单独保存 JSON，便于后续排查、复跑和字段扩展。
失败记录
HTTP 404、超时或异常不会中断批次，会写入失败列表方便人工复核。

08技术难点

Excel 行块解析
源表不是标准一行一条记录，而是每 5 行组成一条企业数据，需要按固定步长抽取。
接口失败不中断
单个 CNPJ 查询失败时记录错误并继续处理后续记录，保证批任务能完整跑完。
字段对齐
将葡语 API 字段转成中文表头，同时保留原始 CNPJ 和 Excel 公司名，方便核对差异。
编码兼容
CSV 使用 utf-8-sig 写入，减少中文 Windows Excel 打开时的乱码概率。

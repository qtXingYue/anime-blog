项目定位

这个项目定位在授权测试与学习环境下的网络可观测性建设：搭建稳定的抓包环境，记录域名、接口类型、SDK 连接、请求链路和 Native 层通信现象，最后沉淀成可复盘的分析报告。

公开作品集只展示方法论、架构和观测结果摘要，不公开敏感接口参数、认证材料、凭据信息或可复现操作步骤。

技术流程

核心实现

流量采集

通过代理与日志链路观察 HTTP/TLS 请求、SNI、CDN 资源和第三方 SDK 连接，整理为接口资产清单。

动态观测

使用 Frida 17 适配新版 API，对 connect、SSL_read、SSL_write 等 Native 调用进行可视化记录。

报告输出

将环境、流程、端点分类、链路判断和风险边界整理成 Markdown 报告，便于后续复盘和展示。

作品集表达

这个项目适合放在“核心工程项目”里，重点体现移动端调试、网络协议理解、动态插桩、问题拆解和文档化能力。相比只写“抓包”，更好的表达是“构建可复用的 Android 网络观测实验平台”。

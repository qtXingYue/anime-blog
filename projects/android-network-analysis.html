MuMu Android Network Lab

MuMu 安卓环境网络调试与协议分析

以 MuMu 模拟器作为 Android 运行环境，配合 ADB、mitmproxy、Frida 17 和 Python 脚本，对自建测试 APK / 授权实验包的网络请求、SDK 连接和 Native 层读写行为进行记录与复盘。

MuMu模拟器调试环境

项目定位

这个项目不是简单写“会抓包”，而是把一次 Android 网络调试过程整理成可复用的实验环境：用 MuMu 模拟器运行测试 APK，通过 ADB 管理设备状态，用 mitmproxy 观察应用请求，再用 Frida 辅助记录 Native 层调用现象，最后沉淀为接口资产表和调试报告。

测试对象采用自建 Android Demo APK 与授权课程实验包，覆盖登录态请求、列表接口、图片资源加载、埋点上报和第三方 SDK 连接等常见场景。这样既能展示真实移动端调试流程，也避免在公开作品集里暴露第三方应用的敏感信息。

公开页面只展示环境搭建思路、观察维度和报告产出，不公开认证材料、具体业务接口参数、可复现绕过脚本或第三方 App 的敏感数据。

测试环境

运行软件

使用 MuMu 模拟器作为 Android 设备，创建干净测试实例，安装自建测试 APK，并通过 ADB 连接到本机调试环境。

观测工具

桌面端使用 mitmproxy 记录 HTTP/TLS 请求，配合 Python 脚本整理域名、路径、状态码和资源类型。

辅助分析

在授权测试包内使用 Frida 17 观察 connect、SSL_read、SSL_write 等调用现象，帮助判断请求链路和 Native 层通信位置。

技术流程

MuMu 实例与 ADB 准备 mitmproxy 流量采集 Frida Native 层观测 接口资产与报告沉淀

MuMu 使用过程

准备独立模拟器实例

在 MuMu 中创建专门的测试环境，保持系统、代理、证书和测试 APK 配置独立，避免影响日常使用环境。

连接 ADB 与安装测试包

通过 ADB 确认模拟器在线，安装自建 Demo APK，记录包名、版本号、运行入口和测试账号类型。

配置代理与采集请求

将模拟器网络指向本机代理，在授权测试场景下打开登录、列表、图片加载、埋点等页面，采集请求链路和响应特征。

整理报告与复盘结论

把域名、接口类型、SDK 连接、异常请求和 Native 层观察结果归档，输出调试报告、接口资产表和环境复现说明。

核心实现

流量采集

通过代理与日志链路观察测试 APK 的 HTTP/TLS 请求、SNI、静态资源、接口路径和第三方 SDK 连接，整理为接口资产清单。

动态观测

使用 Frida 17 适配新版 API，对授权测试包中的 connect、SSL_read、SSL_write 等 Native 调用进行可视化记录。

报告输出

将 MuMu 环境配置、测试路径、端点分类、链路判断和风险边界整理成 Markdown 报告，便于后续复盘和展示。

作品集表达

这个项目适合放在“核心工程项目”里，重点体现移动端调试、网络协议理解、模拟器环境管理、动态插桩、问题拆解和文档化能力。相比只写“抓包”，更真实的表达是“用 MuMu 模拟器搭建 Android 授权测试环境，并把一次网络调试过程沉淀成可复盘的方法和报告”。

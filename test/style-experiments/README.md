# style-experiments — 视觉风格实验(仅评估用)

四套与当前「暗紫杂志风」完全不同方向的原型,均为**自包含单文件 HTML**(样式/封面图内联,系统字体栈,国内可直接打开),用你的真实内容(钟文清 / QT新月 / 12 个项目 / 蓝桥杯·N2·HCCDA)搭建,含 hero + 数据 + 技能 + 项目 + 页脚。双击任意 `.html` 即可看完整效果。

**这些只是风格试验,不接入现有站点,也不影响 test/ 里的 P0 改动。**

## 四个方向

- **A · 瑞士极简**(`A-swiss-minimal.html`)— 浅色纸底 + 超大无衬线标题 + 严格网格 + 单一红色。编辑设计感、克制、留白多,项目做成带序号的清单。适合想走「高级、干净、专业」路线。
- **B · 终端极客**(`B-terminal-geek.html`)— 近黑背景 + 全等宽字体 + 终端窗口(命令行 `whoami` / `cat facts.json` / `ls projects/`)+ 绿色。极强开发者身份感,最「懂行」也最有记忆点,但偏小众。
- **C · Bento 科技**(`C-bento-tech.html`)— 暗色 + 玻璃拟态 + 大小不一的 Bento 卡片拼贴 + 渐变高光。当代科技产品风(类 Linear/Vercel 落地页),现代、premium,和你现有暗色调最容易衔接。
- **D · 杂志暖色**(`D-editorial-warm.html`)— 米色纸感 + 宋体大标题 + 首字下沉 + 墨色/酒红双色。像一本印刷杂志封面,优雅、有人味、独特。**注意**:大标题用系统宋体,在你的 Windows 上会渲染成真正的宋体衬线(比截图里的效果更精致)。

## 怎么评估

对着 `对比总览.png` 先扫一眼四种方向,选中意的再双击对应 HTML 看完整版。选定后告诉我编号(可以混搭,比如「C 的布局 + A 的字体」),我把它做成真正的 Astro 组件接进站点。

各风格目前只做了首页级别的观感验证,详情页/交互/移动端适配会在你选定方向后再补齐。
